# V00600-10761 [Hogugu][Customer]Support open therapist profile page from push notification

**Requiremnt:**

  
HOGUGU wants to send push notifications to customers. When a customer taps a notification, the app should open the corresponding therapist’s profile page.

If the therapist’s profile is no longer available or the therapist data is invalid when the notification is tapped, the app should open the home screen instead.

Additionally, when the customer taps the corresponding notification from the timeline screen, the app should also open the therapist’s profile page.

To support this behavior, we need to define the push notification metadata format so that Shakebrain can use it when sending notifications to the customer app.

The required metadata must also be passed to our notification service so that the app can identify the target therapist and navigate to the correct profile page.  
  
Scope: Customer (android/ios)

  
We will start with supporting plain text push content 1st, in the next phase, might need support more complex structure.
