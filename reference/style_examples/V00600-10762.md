* **Waiting Time for Time-Specific Booking Requests**  
  Change the waiting period for time-specific booking requests from the current **20 minutes after the request is sent** to the earlier of:

    * **24 hours after the request is sent**, or
    * **45 minutes before the booking start time**  
      If no therapist accepts the request by that time, the request will be automatically canceled.
    
* **Notifications to Therapists**

    * **Current behavior:**  
      Each therapist receives only one notification after the booking request is sent.
    * **Updated behavior:**  
      Send notifications at the following times:
    
        * Immediately after the request is sent
        * 5 minutes after the request is sent
        * 10 minutes after the request is sent
        * 15 minutes after the request is sent
        * Every hour from 6 hours before the booking start time:  6->5->4->3->2->1
        * The booking request will be automatically canceled **45 minutes before the booking start time** if it has not been accepted.
        * If a therapist closes the popup, they will still receive subsequent push notifications.
        * Push notifications are sent only to therapists who matched the conditions when the customer submitted the request.
        * Even if a therapist’s conditions change during the waiting period, keep the NOW request active and continue sending push notifications.
