## 2. Remove Excel forced-text formatting

* The export currently wraps every cell value as `="value"` (an Excel trick to prevent auto-formatting of things like leading zeros or dates).
* Requirement: output a plain, standard CSV without this wrapping.

## 3. Add a "安心サポート料" column

* This is an existing, named fee concept already used elsewhere in the system (not something new to define) — it replaced two older fees (bank fee + crisis management fee) starting from a newer commission model.
* Add it as its own column, placed near "危機管理手数料" / before "消費税" and "支払い金額", since these fees are mutually exclusive depending on which commission period a payout falls under.
* For older payout periods where this fee doesn't apply, display ¥0.
