# V00600-10080 [Hogugu] Auto-cancel booking request if therapist does not respond within 24 hours | 機能追加依頼_リクエスト送信後24時間以内にセラピが未対応の場合自動キャンセル処理

## Background

After a customer sends a booking request, some therapists not respond — no chat contact / no call and neither approval nor decline. The operations team chases the therapist by LINE and phone for requests that have been left for a while, but sometimes there is still no response. In that case Ops manually cancels the booking and notifies the customer by email that the therapist was urged but did not reply.

Currently the system auto-cancels a booking only when it reaches **45 minutes before** the booking date/time. There is no automatic handling for a request that is left unanswered shortly after it is sent.  
  
**24h +  no chat contact / no call and neither approval → Auto respond → Remove  -**

## Purpose

Remove the manual operational burden of chasing unresponsive therapists and cancelling case by case, and give customers a timely, predictable outcome instead of being left waiting.

## Requirement

* Change the spec so the system **automatically cancels a booking request when the therapist takes no action on it within 24 hours after the request is sent** — i.e. the therapist does **not accept (approve)** the request, does **not call** the customer, and does **not send any chat message**. This is in addition to the existing 45-minutes-before auto-cancel.
* **Scope:** applies to **standard request bookings** only. **NOW bookings are out of scope** (they are immediate and have no request-waiting window).
* **Therapist penalty:** Same with currernt 45min cut-off
