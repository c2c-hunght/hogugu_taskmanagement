## Description (Jira raw)

## Background

The customer app's search/home screen currently shows a **“new therapist” slider** — a generic list of newly-joined therapists that is the same for everyone and not tailored to the individual customer.

## Requirement

* Replace the **new-therapist slider** with a **personalized therapist recommendation list**, similar to Amazon's product recommendations.
* The list is generated **based on the customer's own data** and sent to that customer.
* The recommendation **calculation must be updatable from the server** — the algorithm / weighting can be changed and tuned server-side **without requiring a customer-app release**.

> **⚠️ Recommendation calculation: not yet defined (waiting for definition).** The exact recommendation logic / algorithm is still to be decided and will be defined separately.

## Purpose

Show each customer therapists that are more relevant to them (instead of a generic new-therapist list), improving discovery and booking conversion, and letting us tune the recommendation logic quickly server-side.

## Affected scope (影響範囲)

* Customer app — search / home screen (replaces the new-therapist slider).
* Server / backend — generates and serves the recommendation; the calculation is configurable server-side.

## Points to confirm (TBD)

* **Recommendation calculation / algorithm — waiting for definition (計算ロジック未定義).** To be defined separately.
* **Input data:** which customer data feeds the recommendation? (e.g. booking history, favorites, viewed / searched therapists, area, menu / price preferences.)
* **Relationship to existing “Recommend” sort:** there is already a rule-based “Recommend” ordering (approval rate → response time → reviews → availability …). Does this personalized list **replace** it, or sit alongside as a separate section?
* **New / low-data customers:** fallback when the customer has little or no history (e.g. popular or nearby therapists)?
* **Availability filter:** should recommendations only include therapists with available timeslots (as the new-therapist slider does today)?
* **Presentation:** list size, ordering, and how often it refreshes.
* **Platform scope:** Customer app only, or also NOW app / Web?

## Reference

Concept: Amazon-style personalized recommendations — a per-customer list driven by that customer's behavior/data, with the ranking model adjustable on the server.
