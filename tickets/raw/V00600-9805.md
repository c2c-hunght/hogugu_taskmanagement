## Description (Jira raw)

## Background

When a customer books a therapist, they can view the following coupons:

* Coupons created by therapists and marked as "display in My Coupons"
* Coupons sent from therapists via the "Send Coupon" function

Coupons are currently distributed through various channels (Shakebrain push notifications; Email, LINE, and other SNS). New functions will be added to support displaying **externally distributed coupons** in the customer app.

---

## Requirements

### 1. Add private coupon support to Hogugu coupons

Add a **coupon type selection** to the coupon create screen:

* **プライベートクーポン (Private coupon)**
* **パブリッククーポン (Public coupon)**

### 2. Specify a customer list per coupon

For a **private coupon**, after the coupon is created the operator defines which customers can use it. Customers can be added in **two ways**:

**a) CSV upload**

* Operator can **remove the CSV and re-upload**, but **cannot** partially update the list
* Operator can **download the CSV**
* CSV validation:

    * Exactly **2 columns**
    * File size **< 10 MB**
    * **Max 500,000 rows**
    * Start reading from the **2nd row** (row 1 = header)
    * `Customer ID` — **required, must be validated**
    * `Customer Name` — reference only, **not validated**
    
* After importing the CSV to the DB, **show the count of valid customers** from that list
* Since the CSV may be large, **processing can take time**. Processing / status behavior:

    * While processing, the CSV shows a **"processing" status**; the valid-customer count is shown once processing completes.
    * During processing the upload area is **locked** — the operator **cannot edit or re-upload** until it finishes.
    * After a **successful import**, the upload area **stays disabled** (no partial update). To change the list, the operator must **remove the CSV and upload again**.
    * On **failure / timeout**, the CSV shows a **"failed" status**. It is **not auto-retried** — the operator must **remove it and upload again**.
    

**b) Through Shakebrain API integration**

* Customers added via the API **cannot be deleted**
* Operator can **download** the list of added customers
* No on-screen customer list is shown (the list may be very large) — **download only**

> **CSV format:** `Customer ID | Customer Name `

Please check the mockup:  coupon-customer-list.html

### 3. Support coupon distribution through SB push notifications

* Add a new parameter `couponCode` to the Shakebrain timeline API
* System stores `couponCode + customerId` pairs in the DB
* `customerId` is added to the customer list from (2) if not already present
* If the coupon code is invalid, **skip that entry and continue** → _define API details_

### 4. Display of coupons and announcements popup at app startup

* Order of Coupons and Announcements in the Popup

* * Display **coupons before announcements**.
  * Coupons should be sorted using the following priority:
  
      1. **First-time-only coupons (初回限定)** should be displayed before coupons that are not limited to first-time users.
      2. Sort by **discount amount**, from highest to lowest.
      
          * For percentage-based coupons, calculate the equivalent discount amount based on **¥10,000**.
          * Example: A 20% discount coupon is treated as a ¥2,000 discount for sorting purposes.
          
      3. If the calculated discount amount is the same, sort by **expiration date**, with coupons expiring sooner displayed first.
      
  
* Display Logic

    * Announcements
    

* * * Keep the current display logic unchanged.
    
  * Coupons
  

* * * **Published coupons with an announcement**
    
        * Keep the current display logic unchanged.
        
    * **Private coupons**
    
        * Display the coupon in the popup after it has been added to the user's coupon list.
        * If a coupon does not have an **announcement image**, display a **default coupon image** instead.
        
    
  
*  UI update

* * Change the ui of coupon in the popup
  
      *  Move the **coupon code below the image** (no longer overlaid on the artwork).
      * Add a **copy button** next to the coupon code — tapping copies that coupon's code to the clipboard, with visual feedback. 
      * After copy the coupon code , that coupon will be auto applied in booking request page
