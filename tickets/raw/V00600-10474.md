## Description (Jira raw)

### **Description**

We have received customer feedback that the current therapist rank badges are difficult to understand because there is no explanation of how the ranking system works.

Originally, a rank description was planned to be displayed together with the rank badge feature, but this requirement was unintentionally omitted during the redesign of the price limit feature based on reviews.

#### Current Behavior

* Only **Silver Rank and above** badges are displayed on therapist profiles.
* Tapping the rank badge does not provide any explanation.

#### Requested Enhancement

Implement a popup that is displayed when a customer taps a **therapist's rank badge**.

The popup should explain the meaning of the therapist ranks and the ranking criteria, based on the content defined in the design specification.

Popup content

```
ランクについて
［プラチナ］
セラピストポイント300TP以上
［ゴールド］
セラピストポイント150TP以上
［シルバー］
セラピストポイント50TP以上
ランクは、直近90日間の施術実績で獲得したセラピストポイントの合計に応じて決まります。
・新規施術：1TP
・リピート施術：4TP
```

#### Expected Behavior

* Customers can tap the therapist rank badge.
* A popup is displayed containing the rank explanation.
* The popup content should follow the approved design/specification.
* The feature applies wherever therapist rank badges are displayed in the Customer App.
