## Description (Jira raw)

### Google Play Policy: App must target Android 16 (API level 36) or higher

Google Play requires all apps to meet target API level requirements. From Nov 1, 2026, if the target API level is not within 1 year of the latest Android release, app updates will be blocked on Google Play.

### Current Status

Current highest non-compliant target API level: Android 15 (API level 35).

### Action Required (by Nov 1, 2026)

1. Update compileSdk and targetSdk to 36 (Android 16) in build.gradle
2. Resolve any compatibility issues or behaviour changes introduced in Android 16
3. Test the app using internal, closed, or open testing on Google Play
4. Publish a new production release before the deadline

### Affected Apps

* Hogugu Customer Android
* Hogugu Therapist Android

**Deadline: November 1, 2026 (extension granted). Failure to comply will block all app updates on Google Play.**
