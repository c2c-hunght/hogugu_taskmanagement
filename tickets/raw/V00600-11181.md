## Issue

A therapist using LINE integration reported a discrepancy in notification timing.

For a 9:00 booking request, the actual auto-cancellation happens at 8:15 (45 minutes before). However, the therapist received a LINE notification at 7:00 stating "this will be automatically cancelled in 15 minutes."

The notification content does not match the actual auto-cancellation time, which could confuse therapists. Please check whether this is a bug in the notification logic/timing, or a spec issue.
