**Background**

1. Iconℹ️ which link to ランクシステムについて(Rank system Explanation）page is hard to notice. Occasionally, Partner receive inquiries from therapists saying they didn’t realize it was there.
2. 失効予定ポイント (Upcoming Expiry Points)

**Requirement**

1. Add 「ランクシステムについて」button to link to 「ランクシステムについて」(Rank system Explanation) page. Still keep the icon ℹ️ display  
2. 失効予定ポイント(Upcoming Expiry Points)page

* Remove minus in front of the point text
*  Change the text color from **Red-> Black**
