* If no weekday is selected, the save button is **disabled**.

**5-3. ？icon popup for 時間帯**
* Tapping the ？icon next to `時間帯` shows this popup:
```
時間帯について
設定した時間帯内に施術が終了する予約のみ受付可能となります。

例）12:00〜14:00を「受付可能（○）」に設定した場合

・12:00開始の90分予約→受付可能（13:30終了）

※設定した終了時刻を超える予約は受付できません。

* Text:
```

期間・曜日・時間帯を指定して、予約枠を
