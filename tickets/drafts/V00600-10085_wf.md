## Overview — flow & review status

```
 Therapist App                                                    Dashboard (Ops)
 ─────────────                                                    ───────────────
 WF-1 Login ──[新規登録]──▶ WF-2 Registration form
                             │
                             ▼
                      OTP screen (existing)
                             │
                             ▼
                      WF-3 ID document ──[あとで提出する]──┐
                             │[提出する]                    │
                             ▼                              ▼
                      Home (logged in) + WF-4 banner / WF-5 popup
                             │
                             └──── ID submitted ────▶ WF-7 list filter 「審査:」
                                                      WF-8 detail: 承認 / 否認
                                                             │
                     WF-6 push (承認 / 否認) ◀────────────────┘
```

| Review status | Meaning | Shown to customers | Banner (WF-4) | App-start popup (WF-5) |
| --- | --- | --- | --- | --- |
| 仮登録 | Registered, ID not submitted | No | 4-A + 4-B | 5-A |
| 審査中 | ID submitted, waiting for Ops | No | 4-A | — |
| 否認 | Rejected by Ops | No | 4-C | 5-B |
| 承認済み | Approved by Ops | Yes, **only if profile completed** | — [Q1] | — |

Existing therapists and therapists created on the Dashboard = **承認済み** (no change for them).
