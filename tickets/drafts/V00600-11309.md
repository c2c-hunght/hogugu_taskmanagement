# V00600-11309 [Hogugu] Securities issues - Oct task

## Background

* Security findings for the Hogugu repositories in the APPSEC project: [APPSEC tickets for Hogugu](https://c2cdoc.atlassian.net/jira/software/projects/APPSEC/list?jql=project%20%3D%20APPSEC%20AND%20textfields%20~%20%22hogugu*%22%20ORDER%20BY%20priority%20ASC%2C%20created%20DESC%2C%20cf%5B10019%5D%20ASC)
* Many of them can be fixed by **upgrading a library / package version** (version up).
* In October we will fix all version-up findings that **do not have a big impact on the system**, and release them with the October version.

## Requirements

### 1. Target

* APPSEC tickets for Hogugu repositories that are fixed by a **version up** of a library, package or SDK.
* Only version ups with **no big impact on the system**:

| In scope (October) | Out of scope (plan later) |
| --- | --- |
| Patch / minor version up with no breaking change | Major version up with breaking changes |
| No change to app / API behavior | Changes app / API behavior or data |
| Little or no code change needed | Needs large code changes or a redesign |
| Normal regression test is enough | Needs a large test scope (e.g. full payment / booking flow retest) |
| | Framework / runtime / OS-level upgrade |

* APPSEC tickets that are **not** version ups (code fixes, e.g. authorization or injection issues) are out of scope for this ticket.

### 2. Classification before starting

* Please list every target APPSEC ticket with: repository, library, current version → fixed version, **In scope (October)** / **Out of scope** and the reason.
* Director will confirm the list.
* Out-of-scope items are kept in the list with their reason, so they can be planned in November.

### 3. Release & test

* All in-scope version ups are released with the **October version** 
* QC tests them together with the October version: regression test of the features that use the upgraded libraries.
* No functional change for users.

### 4. After release

* Each fixed APPSEC ticket is updated (fixed version + release) so the AppSec team can close it.

## Scope

* All Hogugu repositories with version-up findings in APPSEC (BE, Web, Dashboard, iOS, Android)
* **Out of scope:** non-version-up findings (code fixes), version ups with a big impact on the system

## Acceptance Criteria

* A classification list (In scope / Out of scope + reason) for all version-up APPSEC tickets is attached to this ticket and confirmed.
* All in-scope version ups are included in the October release.
* QC regression test passes for the October version with the upgrades included; no functional change for users.
* Each fixed APPSEC ticket is updated with the fixed version and release.
* Out-of-scope items remain listed with their reason.
