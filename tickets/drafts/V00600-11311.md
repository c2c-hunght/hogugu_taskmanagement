# [Hogugu][Dashboard][BE][Customer] Point-up campaign settings in the Dashboard | ポイントアップキャンペーンを管理画面から設定

## Background
* We want to run **time-limited customer point campaigns** (e.g. Black Friday) whenever needed.
* Today each campaign needs Dev work (settings change or a one-off batch). Operations wants to **create campaigns in the Dashboard**, the same way as coupons.
* Examples:
  * 「9/19〜9/27の期間中、10,000円以上利用したカスタマーへ10％ポイント還元」
  * 「指定したカスタマーIDに対して、期間中の利用で1,000ポイント還元」
* When a customer meets the conditions, the points are granted **automatically**.
* In addition, the **current point-up campaign becomes permanent** (no end date).

## Requirements
### 0. Current point-up campaign → permanent
* The current point-up campaign (the point rate by booking order, set for 10/01–10/31 in V00600-11474) continues **without an end date** from 11/01.
* The rule (rates by booking order) is **unchanged**.
* It must be in place **before 2026-11-01 00:00 JST**, so there is no gap after the October campaign ends.
* UI changes for the permanent point-up (texts with the campaign period, 「キャンペーン中」 display, etc.) are described in a **separate ticket**.

### 1. Campaign settings (Dashboard)
New menu 「ポイントキャンペーン」: list, create, edit, stop.

| Field | Rule |
| --- | --- |
| キャンペーンタイトル | Required. Shown to customers (point history label, point screen). |
| キャンペーン期間 | Required. Start 00:00 – end 23:59 JST. Judged by the **treatment completion date** (charged cancellation: cancellation date, see §2). |
| 対象 | Required. Select **one or more** of **メインアプリ / NOW / Web / インバウンド**. |
| ユーザーセグメント | One of: **初回限定** / **リピート** / **カスタマーID指定 (CSV)** |
| 最低利用金額 | Optional. e.g. 10,000円以上 |
| 還元方法 | One only: **◯％還元** (1–100% of the booking amount) or **◯ポイント還元** (fixed points). No 「◯倍」 setting. |
| 付与ポイントの有効期限 | Required. **N days after the grant.** |
| 説明文 | Optional. Max **1,000 characters** (文字). Free text shown on the campaign explanation page (§3). |
| 詳細URL | Optional. Link to an explanation page / LP, shown on the campaign explanation page (§3). |

* 初回限定 = customer with **no completed booking before, on any channel**.
* リピート = customer with at least 1 completed booking before (any channel).
* CSV: one customer ID per row, no maximum. Invalid / unknown IDs are listed after upload and skipped.
* A running campaign can be stopped.
* While running, only **title** and **end date** can be changed. The new end date must be today or later (no past date).

### 2. Point grant
* When a target customer's booking on a target channel **completes and is paid** within the period, and meets the minimum amount, campaign points are granted **automatically**.
* **Charged cancellations** (キャンセル料あり) also earn campaign points, on the same amount as their normal points. The cancellation date is used as the date for the period.
* Amount used for 「％還元」 and 「最低利用金額」: the same amount as normal points (menu + midnight fee + extensions − coupon). Points used for payment are not deducted.
* ％還元: points = amount × ％, rounded down. No upper limit per booking.
* ◯ポイント還元: granted **per booking** in the period (every qualifying booking).
* The granted points are **期間限定ポイント**, valid for the N days set in §1, shown in point history with the campaign title.
* Campaign points are granted **in addition to** normal points and the current point-up rate.
* If 2 or more campaigns match the same booking, **all** of them are granted.
* If the booking is cancelled / refunded after the grant, the campaign points are revoked.

### 3. Show the campaign in the app
**3-1. Point screen link**

| State | Link text on the point screen |
| --- | --- |
| No campaign for this customer | `ポイント詳細はこちら` (unchanged) |
| At least 1 running campaign from §1 **for this customer** | `キャンペーン中！詳細はこちら` (same text as today) |

* "For this customer" = the customer matches the campaign's segment (初回限定 / リピート / CSV). Campaigns for other customers are not shown.
* The permanent point-up (§0) does not switch the link to 「キャンペーン中」; its display is defined in the separate UI ticket.

**3-2. Explanation page**
* Tapping the link opens the point explanation page. Running campaigns for this customer are shown **at the top**, one block per campaign, newest first. The current explanation content stays below.
* Each block is built from the Dashboard settings:
```
＼ {キャンペーンタイトル} ／
期間：{開始日}〜{終了日}
対象：{対象 (例: メインアプリ・Web)}でのご利用
対象のお客様：{初回ご利用のお客様 / 2回目以降のご利用のお客様 / 本キャンペーンの対象のお客様}
条件：1回のご利用金額が{最低利用金額}円以上
特典：ご利用金額の{◯}％をポイント還元 / 1回のご利用ごとに{◯}ポイント還元
有効期限：ポイント付与から{N}日間
付与時期：施術完了後に自動で付与されます

{説明文}

詳しくはこちら（{詳細URL}）

※ご利用金額は、メニュー料金・深夜料金・延長料金の合計からクーポン割引額を差し引いた金額です。
※予約がキャンセル・返金された場合、付与されたポイントは取り消されます。
※期間限定ポイントのため、有効期限を過ぎると失効します。
```
* Lines without a setting are hidden: 条件 (no minimum amount), 説明文, 詳しくはこちら (no URL).
* `本キャンペーンの対象のお客様` is used for the CSV segment.

**3-3. Other**
* Operations can also announce a campaign with the existing お知らせ / banner (Dashboard → Announcement).
* No push / timeline message when a campaign starts.

## Scope
* Dashboard, BE
* Customer iOS / Android, NOW, Web (booking.hogugu.com incl. INBOUND): campaign display on the point screen (§3). Point history needs no change (the label comes from the server).

## Acceptance Criteria
* From 2026-11-01 the current point-up rates still apply, with no end date and no gap after 10/31.
* Operations can create, list and stop a campaign with all fields in §1, incl. CSV import.
* While running, only the title and end date can be changed; a past end date is rejected.
* Target customer completes a booking on a target channel in the period with amount ≥ minimum → campaign points are granted automatically, with the right amount (％ rounded down, or fixed points per booking) and expiry (N days), labelled with the campaign title.
* A campaign can target several channels; non-target customer, non-target channel, amount below minimum, or completion outside the period → no campaign points.
* 初回限定 (no completed booking on any channel) / リピート / CSV segments are judged correctly.
* A booking matching 2 campaigns receives both.
* Charged cancellation in the period → campaign points granted on the same amount as normal points.
* Campaign points are added on top of normal points and the current point-up rate.
* Booking cancelled / refunded after the grant → campaign points revoked.
* No double grant for the same booking and campaign.
* Customer with ≥ 1 running campaign for them → link text `キャンペーン中！詳細はこちら`; otherwise `ポイント詳細はこちら`.
* The explanation page shows one block per running campaign for this customer, built from the Dashboard settings; empty optional lines are hidden; campaigns for other customers are not shown.

## Out of scope
* New 「◯倍」 campaigns (the current point-up rate stays as is, see §0)
* UI changes for the permanent point-up (separate ticket)
* Push / timeline message at campaign start
