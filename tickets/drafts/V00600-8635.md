# V00600-8635 [Hogugu][Therapist]My Rank page_ Request to adjust 2 points of design|マイランクページについて2点デザイン修正

## Background

Source: TS2-1241 「セラピapp_マイランクページについて2点デザイン修正」.

1. The ℹ️ icon that links to the 「ランクシステムについて」 (Rank system explanation) page is hard to notice. The partner occasionally receives inquiries from therapists who did not realize it was there.
2. 失効予定ポイント (Upcoming Expiry Points): a minus sign is shown in front of the point value. Therapists may think that once the negative amount is deducted, it turns into a positive number → confusing.

## Current Behavior

* My Rank page: the Rank system explanation page is reachable only via the ℹ️ icon.
* 失効予定ポイント: the point value is shown with a minus sign, in red.

## Requirements

### 1. 「ランクシステムについて」 button
* Add a 「ランクシステムについて」 button that links to the 「ランクシステムについて」 (Rank system explanation) page.
* **Keep** the ℹ️ icon displayed.

### 2. 失効予定ポイント (Upcoming Expiry Points) page
* Remove the minus sign in front of the point value.
* Change the text color from **red → black**.

* Design: see Reference (final design, V00600-7109).

## Scope

* Therapist app (iOS / Android)

## Acceptance Criteria

* The 「ランクシステムについて」 button is shown on the My Rank page and opens the Rank system explanation page.
* The ℹ️ icon is still shown and still opens the same page.
* 失効予定ポイント shows the point value **without** a minus sign, in **black** text.
* Same behavior on iOS and Android.

## Out of scope

* No change to rank / point calculation or to the content of the Rank system page.
