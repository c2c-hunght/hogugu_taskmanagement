# V00600-8637 [Hogugu] Check Get Review API speed for hogugu.com and improve if slow

## Background
* The Get Review API used for the review display on hogugu.com (see V00600-3065) **was slow**: 7.38 s in the investigation V0060B-1338.
* Since then the review schema was updated (V0060B-1198), which may have improved the speed.
* **Target:** response **below 1 second**.

## Requirements
### Step 1. Check the current speed
* Please measure the current response time of the API on **PROD** (and STG for comparison) and share the result in this ticket (average / max, number of requests, date).

### Step 2. Decide by the result
| Result | Action |
| --- | --- |
| **< 1 s** | No change. Report the measured speed in this ticket → close. |
| **≥ 1 s** | Improve the API as in Step 3. |

### Step 3. Improvement (only if ≥ 1 s)
* Please investigate the cause and propose the improvement (approach + estimate) in this ticket before implementing.
* The endpoint and response fields stay the same (no change for hogugu.com).
* Reference: an earlier implementation exists on branch `feature/V00600-8637` (PR #214, not merged).

## Scope
* BE (review service). No app / web change.

## Acceptance Criteria
* The current PROD response time is measured and written in this ticket.
* If < 1 s: the ticket is closed with the result; no code change.
* If ≥ 1 s: the cause and the improvement proposal are written in this ticket; after the improvement, the PROD response time is < 1 s with the same response format.

## Out of scope
* Changes to the hogugu.com front end and to the response format.
