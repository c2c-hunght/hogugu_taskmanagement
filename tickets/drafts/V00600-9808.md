# V00600-9808 [Hogugu][Therapist][Customer][Dashboard] Therapists can set multiple profile images (max 5)

## Background
* Many customers choose a therapist based on the profile image. We want therapists to show more than one profile picture.

## Current Behavior
* Each therapist has one profile image. It is optional (it can be deleted).

## Requirements
### 1. Therapist App
* Therapists can upload multiple profile images (**maximum 5**) and set **one image as the default**.
* Upload rules (format, size, no crop / edit): **same as today**.
* The therapist can **reorder** the images.
* When the default image is deleted, the **next image** becomes the default.
* 0 images is allowed (same as today).
* No Ops review: new images are shown to customers right away.
* Existing data: the current image becomes image #1 and the default. No action needed from the therapist.

### 2. Customer App / NOW / Web
#### Search result & therapist profile page
* Show that the therapist has multiple profile images.
* Customers can tap the image area to view and browse the other images.

#### Other screens
* Other screens (e.g. chat avatar, booking detail, favourites, review list) show **only the default image**.

### 3. Dashboard
* Operators can view **all** of a therapist's profile images.
* No delete function (same as today).

## Scope
* BE, Therapist App (iOS / Android), Customer App (iOS / Android), NOW, Web (booking.hogugu.com incl. INBOUND), Dashboard
* LINE front: **TBD** (decided separately).
* Release order: BE → Therapist app (upload) → Customer / NOW / Web display. Customers see multiple images only after the Therapist app release.

## Acceptance Criteria
* The therapist can upload up to 5 images; the 6th is blocked with a message.
* The therapist can set the default image, reorder and delete images; deleting the default makes the next image the default.
* Existing therapists keep their current image as image #1 / default.
* Customers can browse all images on the search result and profile page (Customer app, NOW, Web).
* Other screens show the default image only.
* The Dashboard shows all images (view only).

## Out of scope
* Video, image captions, per-image ordering by Ops
* Ops review / approval of images
