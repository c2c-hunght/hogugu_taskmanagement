# [Hogugu][Therapist][BE] First treatment bonus +6TP within 30 days of account creation | 初施術ボーナス（登録30日以内）

> Summary option (only if you want the period in the title): `... | 初施術ボーナス（登録30日以内）キャンペーン 10/15〜12/31`

## Background

* Partner request: to help new therapists get started, give a TP bonus when a new therapist completes a treatment soon after the account is created.
* Current TP bonus settings:
    * NOW (フリー予約) treatment: +1TP (campaign-based)
    * HOGUGU first-time customer repeats the same therapist within 30 days: +4TP
* This ticket adds a **third bonus** as a **campaign** (2026-10-15 〜 2026-12-31). The two bonuses above do not change.

## Requirements

### 1. Bonus rule

| Item | Rule |
| --- | --- |
| Bonus | **+6TP** |
| Target therapists | Account created **within the campaign period** (see 4) |
| Start of the 30 days | Therapist **account creation date/time** = 「**アカウント作成日**」 shown on the Dashboard therapist detail (not the profile completion time, not the time the therapist becomes searchable) |
| Judged by | **Treatment completed = payment completed** date/time |
| Condition | Completed within **30 days**: until **23:59 (JST) of the 30th day**; the account creation day is **day 1** (e.g. created 10/15 → until 11/13 23:59) |
| How many times | **Once per therapist** — the first completed treatment only |
| Booking types | Both 指名予約 and フリー予約 (NOW) |

### 2. Target / not target

| Case | Bonus |
| --- | --- |
| 通常会計 (normal checkout) | **+6TP** |
| 未施術会計 (finish without treatment) | Not target |
| 有償キャンセル (paid cancellation) | Not target |

* 未施術会計 and 有償キャンセル do not get the normal TP either, so this bonus follows the same rule.
* If the booking is later cancelled by an admin and its TP is taken back, this bonus is taken back too.

### 3. Stacking

* The bonus is added **on top of** the normal TP and the other bonuses (+1TP NOW, and any bonus added in the future). Example: a new therapist's first NOW booking with a first-time customer = normal TP + 1 + 6.

### 4. Campaign period

| Item | Rule |
| --- | --- |
| Period | Start **2026-10-15 00:00 (JST)** (planned) 〜 end **2026-12-31 23:59 (JST)** |
| Start setting | The start is always set to a time **after the PROD release**. If the release is after 10/15, the start moves to after the release (no retroactive grant). |
| Target | Therapists whose **アカウント作成日 (Dashboard)** is within the period |
| Account created before the campaign start or after 12/31 23:59 | Not target (even if the first treatment is completed within the period) |
| Account created late in the period (e.g. 12/20) | **Target.** The 30 days apply to every target therapist, also after 12/31 (e.g. created 12/20 → until 2027-01-18 23:59) |

* Please make the period start / end **configurable** (env or server setting), so it can be extended or changed without a release.
* BE, Dashboard and Therapist App (iOS / Android) are released **at the same time**, before the campaign start.

### 5. Display

* The bonus is shown in the therapist's point history (Therapist App) and in the Dashboard therapist point history.
* Label (Therapist App and Dashboard): **「初施術ボーナス（登録30日以内）」** (new label → Therapist App release needed).
* If the bonus is taken back: **「付与取消(初施術ボーナス)」**.
* **Old Therapist App versions** (before this release) must not show a UI bug for the new history rows (no crash, no blank label, no layout break).
    * Please share how the new rows will be shown in old versions before development.

## Scope

* BE (point calculation)
* Dashboard: point history label
* Therapist iOS / Android: point history label

## Acceptance Criteria

* A therapist whose account was created within the campaign period and whose treatment is completed (通常会計) within 30 days of account creation receives +6TP.
* Account created 1 minute before the campaign start → no bonus; created at the start → target.
* Account created 12/31 23:59 → target; created 2027-01-01 00:00 → no bonus.
* Created 12/20 → completed 2027-01-18 23:59 gets the bonus; completed 2027-01-19 00:00 does not.
* Completion after 30 days → no bonus.
* 未施術会計 / 有償キャンセル → no bonus.
* The second and later completed treatments within 30 days do not get the bonus.
* Both Main booking and Now booking count.
* The bonus stacks with normal TP and +1TP NOW.
* Admin cancellation of the booking takes the bonus back.
* The bonus is shown with the agreed label in the Therapist App and Dashboard point history.
* Created 10/15 → completed 11/13 23:59 gets the bonus; completed 11/14 00:00 does not.
* Admin take-back is shown as 「付与取消(初施術ボーナス)」.
* Old Therapist App versions (iOS / Android): the bonus and take-back rows are shown as shared by Dev — no crash, no blank label, no layout break; the point value and total are correct.
* The period can be changed by setting, without a release.
