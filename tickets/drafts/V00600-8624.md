# V00600-8624 [Hogugu][NOW][TS] NOW Matching Issue – "This booking cannot be accepted" message displayed

**Source:** Reported via Technical Support ticket TS2-1412

## Issue

Therapists received a NOW booking request and tried to accept it, but got `この予約リクエストは受け付けられません` even though no other therapist had accepted the booking yet.

* **Booking ID:** 124781423211302 (NOW, 2025/10/28 22:01 → 23:00, 港区). Customer canceled at 22:12.
* **Therapist IDs:** 169003518487309 (tried to accept at 22:05), 190043538522634
* **Date:** 2025/10/28

## Investigation result

* The request (push / popup / list) is sent to the therapists who matched the conditions **when the customer sent the request**.
* When the therapist taps accept, the conditions are **checked again at that moment** (NOW enabled, area, menu, gender, free time slot at the booking start time, not blocked by the customer).
* If anything changed in between (e.g. the therapist changed schedule / NOW setting, or the time slot is no longer free), the accept fails with `この予約リクエストは受け付けられません`, although the therapist still sees the request.
* Decision (2025-11-17): **change the condition of the booking request notification**. The date/time used for the accept check is **not changed**.

## Request

* A therapist sees and receives a NOW request **only while they still meet the conditions** for that booking (same check as when accepting).
* If a therapist no longer meets the conditions:
    * No more push notifications for that request.
    * The request is removed from the therapist's NOW request list / popup.
* The accept check itself is not changed.
* **Applies to NOW immediate bookings only.** Time-specific bookings keep the current rule from V00600-10762 (request stays active and pushes continue even if conditions change).

## Acceptance criteria

* Therapist still meets the conditions → receives the request and can accept it (no change from now).
* Therapist's conditions change after the request was sent (e.g. turns NOW off, removes the area, time slot becomes busy) → the request is no longer shown and no more push is sent to that therapist.
* The message `この予約リクエストは受け付けられません` is shown only when another therapist accepted at the same moment or on a system error.
* Other therapists who still meet the conditions are not affected.
* Time-specific bookings: no change.

## Scope

* BE, Therapist App (iOS / Android)

Also returns nothing if the MQ call errors (`.catch → []`).
