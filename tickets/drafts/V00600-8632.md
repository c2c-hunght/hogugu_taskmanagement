# V00600-8632 [Hogugu][Therapist] Improve the NOW request notification/popup |セラピストアプリ改修_NOW個別設定の廃止

## Background

* Partner request (TS2-1370): along with removing the separate NOW settings, the partner wants therapists to understand the NOW flow better in the Therapist App.
* Many therapists will receive NOW requests for the first time, so they need to know how to handle a NOW request and how NOW affects their evaluation.

## Requirements

### 1. NOW request guide popup

* Show a guide popup when a therapist receives a NOW request, starting from the **first** NOW request, so the therapist understands how to handle it.
* Same style as the existing popup for "payment without treatment" (未施術会計): explanation text + close / confirm button.
* The popup has a **「次回から表示しない」 (Do not show again)** checkbox.
    * Checked → the popup is not shown again.
    * Not checked → the popup is shown again on the next NOW request.
* "Do not show again" is saved **per device** (same as the existing 「次回から表示しない」 popups in the Therapist App). On a new device or after reinstalling the app, the popup is shown again.
* Therapists who already received NOW requests before this release: show the popup to them too? **TBD — to confirm with the partner.**
* Timing: the guide popup is shown **before** the NOW request popup; after 「閉じる」 the request popup / list is shown.
* The popup has a link to the NOW guide page (Requirement 2).
* Wireframe and texts (JP only): see **WF-1** below.
* In the Therapist App, NOW is called **「フリー予約」**; all texts use this name.

### 2. NOW guide page

* Add a guide page that explains:
    * how NOW works
    * how NOW requests are handled (receive → accept / decline → arrival → treatment)
    * what affects the therapist's evaluation
* Same style as the existing Therapist Rank explanation page (マイランク → 「ランクシステムについて」).
* The content can be updated **without an app release** (same as the Rank explanation page).
* Entry points: guide popup link (#103) + フリー予約 settings page (マイページ → フリー予約) (#202).
* Page content and layout: see **WF-2** below (JP only, same as the Rank page).

### 3. Design

* Design for the popup and the guide page: Creative sub-task V00600-11341 / Creative Task V00600-11342 (Work In Progress).
* The WF below is a simple guide for the design; the final design (Figma) will be linked here.

#### Page content (JP — for the designer)

**① フリー予約とは**
```
お客様がセラピストを指名せずに予約をリクエストする機能です。
エリア・メニュー・時間などの条件に合う複数のセラピストに同時にリクエストが届き、
最初に「予約を受ける」をタップしたセラピストに予約が確定します。
```

**② 2種類のリクエスト**

| | 今すぐ予約 | 日時指定 |
| --- | --- | --- |
| 内容 | お客様がすぐに施術を希望 | お客様が日時を指定 |
| 予約を受けられる期限 | リクエストから**20分**以内 | 施術開始の**45分前**まで |
| 期限を過ぎると | 自動でキャンセル | 自動でキャンセル |

```
お返事がない場合は、5分・10分・15分後にもお知らせが届きます。
```

**③ 対応の流れ**
```
1. リクエストを受信（プッシュ通知／ホームの「フリー」タブ）
2. 住所・メニュー・料金・到着希望時間を確認
3. 「予約を受ける」または「お断りする」を選択
   ※ほかのセラピストが先に予約を受けた場合は、予約は成立しません
4. 今すぐ予約の場合：到着時間をチャットでお知らせ
5. 施術・完了
```

**④ 料金について**
```
フリー予約の料金はエリアごとに一律です。
ご自身で設定した料金（指名予約の料金）は適用されません。
リクエストに表示される料金をご確認ください。
```

**⑤ ポイント・評価について**

The bonus line is shown **only during a NOW bonus campaign** (image updated by Ops at the start / end of the campaign; no app release).
```
・フリー予約の施術完了でも、通常の予約と同じくセラピストポイントが付与されます。
・【キャンペーン期間中のみ掲載】キャンペーン期間中は、フリー予約の施術完了でボーナスポイントが付与されます（履歴：「ボーナス(フリー予約)」）。
・リクエストをお断りした場合や、お返事しなかった場合のポイント減算はありません。
・予約を受けた後のキャンセルは「確定予約キャンセル」となり、ポイントが減算されます。
  受けられるリクエストだけを受けてください。
```

**⑥ よくある質問**
```
Q. 「予約を受ける」をタップしたのに予約が成立しませんでした。
A. ほかのセラピストが先に予約を受けたか、お客様がリクエストをキャンセルしました。

Q. リクエストをお断りするとペナルティはありますか？
A. お断りした場合や、期限までにお返事しなかった場合でも、ポイントは減算されません。
```

* The popup follows the approved design and text.

* The guide page content can be changed without an app release.
* Verified on Therapist iOS and Android.
