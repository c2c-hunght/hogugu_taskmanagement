## Draft description (to push)

## Background
* **Phase 3** of the sign-up improvements to reduce drop-offs (#1 V00600-8597, #2 V00600-9029).
* We want users to feel comfortable entering their profile. Today the name and full birthday look like personal data that users hesitate to give.

## Requirements

### 1. Name field
Applies to the sign-up screen, the profile edit screen, and the error messages for this field.

| Item | Current | Expect |
| --- | --- | --- |
| Label | `登録名` (Customer app, NOW, Web) | `ニックネーム` |
| Placeholder | `ほぐぐ 太郎` (Customer app, NOW), `山田 太郎` (Web), none (LINE) | `HOGUGU内でのユーザー名` |

* LINE already uses the label `ニックネーム`; only the placeholder is added.

### 2. Birthday
Applies to the sign-up screen and the profile edit screen.

| Item | Current | Expect |
| --- | --- | --- |
| Input | Year / month / day | **Year + month only** |
| Note | – | Show under the field: `年齢確認のみに使用し、他の目的には利用しません。` |

**Rules**
* Only users aged **18 or over** can sign up. The check uses year + month: a user whose 18th birthday is in the **current month is allowed**.
* Birthdays already saved for existing users do not change.

### 3. Introduction code input (sign-up screen)
* Update the layout as in the design.

### 4. Credit card registration screen (sign-up flow, Customer app + NOW + Web)
* Change the order of the register button (`登録画面へ` on Customer app / NOW, `登録する` on Web) and the `あとで登録する` button as in the design.

### 5. Review list
* Show the reviewer's icon based on the customer's gender (male / female / other), as in the design.
* LINE currently shows no reviewer icon. Add it, same as Web.

## Scope
| Item | Customer app (iOS / Android) | NOW | Web (booking.hogugu.com) | LINE |
| --- | --- | --- | --- | --- |
| 1. Name field | ✓ | ✓ | ✓ | ✓ (placeholder only) |
| 2. Birthday | ✓ | ✓ | ✓ | ✓ |
| 3. Introduction code | ✓ | ✓ | ✓ | ✓ |
| 4. Card screen | ✓ | ✓ | ✓ | – (no "register later" step) |
| 5. Review list | ✓ | ✓ | ✓ | ✓ (new icon, same as Web) |

## Acceptance Criteria
* The name field shows `ニックネーム` with the placeholder `HOGUGU内でのユーザー名` on sign-up and profile edit. Error messages use `ニックネーム`.
* On sign-up and profile edit, the user can choose only the year and month for the birthday, and the note is shown under the field.
* A user under 18 cannot complete sign-up. A user whose 18th birthday is in the current month can.
* Existing users' birthdays are unchanged after release.
* The introduction code input, the card screen buttons, and the review icons match the design. Both card buttons still work as before.

## Out of scope
* Changing birthdays already saved for existing users.
